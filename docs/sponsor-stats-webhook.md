# المطلوب: webhook أرقام الرعاة (لمشروع الأتمتة)

الهدف: صفحة بسيطة في وَصْل يفتحها الراعي (بساطة، صيدلية، بنك...) من لينك خاص بيه، ويشوف فيها
**كام مصلحة اتقضت عنده للعملاء الصم**. أرقام إجمالية بس، ومن غير أي بيانات شخص.

> الصفحة نفسها هتتعمل في الـrepo بعد ما الـwebhook يشتغل. الـrepo مش هيتصل بأي عنوان قبل ما تأكده.

## 1. العنوان والطلب

- **العنوان المقترح:** `POST https://api.nrg-egypt.com/webhook/wasl-sponsor-stats`
  (لو اخترتوا اسم تاني، ابعتوه وهنستخدمه زي ما هو).
- **الـbody** (JSON، زي باقي webhooks وَصْل):

```json
{
  "k": "wasl-nrg-2026",
  "sponsor": "basata",
  "key": "3f9c0d7e1a2b4c5d6e7f8091",
  "from": "2026-11-01",
  "to": "2026-11-30"
}
```

| الحقل | إيه هو |
|---|---|
| `k` | تعريف التطبيق (نفس الموجود في الصفحات، مش سر) |
| `sponsor` | كود الراعي: حروف إنجليزي صغيرة وأرقام و`-` (3–40 حرف) |
| `key` | **مفتاح خاص بكل راعي**: 24 حرف hex. بيتولّد ويتخزن في n8n بس (data table)، والراعي بياخده جوه لينكه: `https://wasl.nrg-egypt.com/sponsor.html#s=basata.<key>`. الـ`#` معناها إن المفتاح مش بيتبعت في سجلات أي سيرفر. |
| `from` / `to` | الفترة بالأيام `YYYY-MM-DD`، بتوقيت القاهرة. أقصى فترة 366 يوم. لو مش موجودين: الشهر الحالي. |

## 2. الرد

```json
{
  "ok": true,
  "sponsor": { "id": "basata", "name": "بساطة" },
  "period": { "from": "2026-11-01", "to": "2026-11-30" },
  "updated": "2026-11-30T21:00:00+02:00",
  "totals": {
    "sessions": 128,
    "staff_joined": 117,
    "one_phone": 9,
    "asked": 102,
    "done": 94,
    "not_done": 8
  },
  "places": [
    { "id": "basata-saft", "name": "بساطة صفط اللبن", "sessions": 41, "staff_joined": 38, "asked": 33, "done": 31, "not_done": 2 },
    { "id": "basata-tanta", "name": "بساطة طنطا", "sessions": 3, "staff_joined": null, "asked": null, "done": null, "not_done": null, "small": true }
  ],
  "by_day": [
    { "day": "2026-11-01", "sessions": 6, "done": 5 },
    { "day": "2026-11-02", "sessions": null, "done": null, "small": true }
  ],
  "company_code": { "devices": 57, "tasks": 403 }
}
```

### معنى كل رقم

| الرقم | بيتحسب إزاي | منين (موجود على السيرفر النهارده) |
|---|---|---|
| `sessions` | عدد مرات فتح كود «وصل في المكان» في أماكن الراعي | `wasl-counter` → `a:"open"` ومعاه `place` |
| `staff_joined` | الجلسات اللي الموظف عمل فيها سكان، أو اتكلم على موبايل العميل | `wasl-counter` → `a:"join"` |
| `one_phone` | جزء من `staff_joined`: الموظف اتكلم على موبايل العميل («الموظف معندوش موبايل؟») | `wasl-counter` → `a:"join"` في وضع الموبايل الواحد (لو السيرفر مش بيفرّق النهارده، رجّعوه `null`) |
| `asked` | الجلسات اللي العميل جاوب فيها على «مصلحتك خلصت؟» | `wasl-counter` → `a:"done"` / `a:"end"` ومعاه `done` |
| `done` / `not_done` | عدد «أيوه» وعدد «لأ» | نفس اللي فوق: `done:"yes"` / `done:"no"` |
| `places[]` | نفس الأرقام لكل فرع. `name` هو اسم الفرع اللي بيظهر للموظف | جدول الأماكن (`place`) |
| `by_day[]` | الجلسات والمصالح اللي خلصت في كل يوم من الفترة، مترتبة من الأقدم للأحدث | تاريخ الجلسة |
| `company_code` | لو الراعي عنده كود شركة: عدد الموبايلات اللي فعّلته، وعدد المهام اللي اتعملت بيه في الفترة. لو مفيش كود: `null` | جدول الكوتة (`wasl-quota`) |

الصفحة هي اللي هتحسب النسب، زي «92% من المصالح خلصت» (`done / asked`). السيرفر يرجّع الأعداد بس.

## 3. قواعد الخصوصية (لازم)

1. **ممنوع في الرد:** أسماء، أرقام تليفونات، رقم الموبايل العشوائي (device)، الـtoken، أي كلام من المحادثات، أو الساعة. التاريخ بالأيام بس.
2. **الأرقام الصغيرة بتستخبى:** أي خانة في `places[]` أو `by_day[]` رقم `sessions` فيها **أقل من 5**، كل أرقامها تبقى `null` ومعاها `"small": true`، عشان محدش يقدر يعرف عميل بعينه. الـ`totals` بتفضل حقيقية لو `sessions` الكلي 5 أو أكتر، ولو أقل كلها `null`.
3. الراعي يشوف أماكنه هو بس. `sponsor` + `key` لازم يتطابقوا، وأماكنه بتتحدد من جدول على السيرفر (مثلاً كل `place` بيبدأ بـ`basata-` تبع `basata`).
4. **مش مطلوب** النهارده عدّ كروت الطلب («فاتورة كهربا»، «معايا روشتة»...) ولا طلبات واتساب لكل صيدلية. الاتنين محتاجين نخزّن حاجة جديدة، ويتضافوا لـ`privacy.html` ويتاخد عليهم موافقة الأول. لو حبيتوهم بعدين، يبقوا حقل جديد (`requests[]`) من غير ما نغيّر الحقول اللي فوق.

## 4. الأخطاء

| الحالة | HTTP | الرد |
|---|---|---|
| `k` غلط | 403 | `{"ok":false,"why":"app"}` |
| `sponsor` أو `key` غلط | 401 | `{"ok":false,"why":"key"}` |
| التواريخ غلط أو الفترة أكتر من 366 يوم | 400 | `{"ok":false,"why":"range"}` |
| طلبات كتير (أكتر من 30 في الساعة لنفس الراعي) | 429 | `{"ok":false,"why":"rate"}` |

مقارنة الـ`key` تكون constant-time، ونفس الرد لو الراعي مش موجود أو المفتاح غلط.

## 5. حاجات صغيرة

- CORS: يسمح لـ`https://wasl.nrg-egypt.com` بس.
- الرد يبقى سريع (أقل من ثانيتين). ممكن تعملوا cache 10 دقايق لكل `sponsor` + فترة.
- `updated`: آخر وقت الأرقام اتحسبت فيه، بتوقيت القاهرة.
- **للتجربة:** راعي تجريبي `sponsor:"demo"` بأرقام ثابتة، عشان نبني الصفحة ونختبرها قبل البيانات الحقيقية.
